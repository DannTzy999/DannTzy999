### 👨‍💻 About Me
I am a **Cyber Security Engineering (D4 Rekayasa Keamanan Siber)** student at **Politeknik Negeri Cilacap**, focusing on **Penetration Testing**, **Vulnerability Research**, and **Web Application Security**.

- 🔍 **Core Focus:** Ethical penetration testing, web vulnerability assessment (OWASP Top 10), and responsible disclosure.
- 🧪 **Hands-On Experience:** Active member of **Cyber Student Community (CYSCOM)**, CTF participant, isolated Docker security lab research, and recognized vulnerability reporter for government/academic portals.
- 🛠️ **Background Advantage:** Solid foundation in web development (PHP, JavaScript, REST API) enabling deeper white-box & black-box security analysis.

---

### 🛡️ Core Competencies
- **Penetration Testing & Vulnerability Research:** Ethical vulnerability discovery, Proof-of-Concept (PoC) development in isolated lab environments, and structured technical mitigation reporting.
- **Web Application Security:** Securing web architectures and source code against common threats such as Broken Access Control, Injection, and File Upload vulnerabilities.
